# Security

pearljs handles private keys, seeds and signing, so please report vulnerabilities privately and do not open a public issue.

To report one, open the repository's Security tab on GitHub and choose "Report a vulnerability". The report goes to the maintainers only.

Include the affected version, what an attacker can do, and a way to reproduce it. Do not send real keys or recovery phrases.

You can expect an acknowledgement and a fix or a decision before anything is disclosed. Please keep the report private until a fixed version is available.

Only the latest release is supported.
